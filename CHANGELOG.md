# Changelog

## v0.2.0

- Clean starter by default; saved-link demonstration and tests are opt-in.
- Declarative extension configuration and product-independent build verification.
- Selective interface refresh, full worker reload fallback and obsolete asset cleanup.
- Machine-readable Playwright diagnostics and prerequisite doctor.
- Verified Windows and Linux development workflows with LF checkout and staged formatting.

## v0.1.0

First versioned Copier release.

- Independently bundled Svelte 5 extension interfaces, typed RPC, reactive storage and accessible UI primitives.
- Frozen pnpm installation, staged formatting, automatic development reload and opt-in browser capabilities.
- Copier generation/update regression tests, Playwright diagnostics and centralized validation.
- Validated release archives, SHA-256 checksums, performance measurements and bundle reports.
- Scheduled lockfile refresh for the template and Dependabot for generated projects.
